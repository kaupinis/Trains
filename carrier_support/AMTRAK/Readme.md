# Processing AMTRAK GTFS Data

- Delete all files in the data directory
- Execute getGTFS
- Copy AMTRAK_GTFS.zip to the data diectory and extract the data.
- Execute updateScriptAMTRAK
- Execute makeAMTRAKRoutes
- Execute makeAMTRAKSkedFiles
- Execute makeAMTRAKTripsFile
- Execute makeAMTRAK_AM3a
- Copy the resulting eo_AMTRAK.js file to the webapp/data directory
